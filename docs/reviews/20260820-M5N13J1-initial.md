#### Important（应该修）

- move_node 移到当前父节点时静默重排到兄弟末尾 — src/novel_editorial/core/structure.py move_node
  - 问题：parent_id 等于节点当前父节点（或节点已在根而传 None）且未传 sort_order 时，走 `_next_sort_order` 取 max+1，把节点静默挪到兄弟末尾；实测 [v, a, b] 调 move(a, parent=v) 变 [v, b, a]。
  - 影响：把当前父节点原样传回的调用方（通用移动 UI、J2 的 structure move --root 当已在根）会无意改序。
  - 修法：parent_id == node.parent_id 且 sort_order is None 时直接返回节点（no-op），不重排、不留事件。

#### Minor（可后补）

- create_node / move_node 未校验 sort_order 非负 — src/novel_editorial/core/structure.py
  - 问题：sort_order=-5 被接受并排到所有兄弟之前；其余参数均有显式校验，唯独 sort_order 没有。
  - 修法：sort_order 非 None 时校验 >= 0，否则 USAGE_ERROR。
