- [P3] db.connect(':memory:') returns a connection with no tables — E:\code\novel-editorial\novel_editorial\db.py:346-364

Treat `:memory:`/`file::memory:?cache=shared` specially (skip the resolve-keyed init cache) or document that file paths are required.
