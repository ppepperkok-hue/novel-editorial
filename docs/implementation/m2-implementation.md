# M2 实施真元文档（Single Source of Truth）

## 总览

- **大阶段**：M2 伙伴完整与信息分层深化——伙伴从工具变成“有自己”的人：完整档案、立场与拒绝、私有记忆、状态沉淀、分层视图与按需检索、叙事追踪、质量门完善。
- **依赖顺序**：按 backlog 依赖列重排（U16 → U17 → U18 → U23 / U19 → U20；U13 → U21 → U22），编号不是实现顺序。
- **基底（不可随意翻）**：技术栈、src 目录结构、数据库表设计（Alembic）、事件契约、错误码、依赖方向。
- **验收总门**：验证四连全绿；无越界实现；每子阶段完成即停，回报三问，经确认后再进下一步。

## 子阶段 A：伙伴完整档案（U16）

- 做什么：`Agent` 表扩展字段：价值观、审美、情绪基线、工作习惯、弱点、人际预设、私心；新增 `agents edit <workspace_id> <agent_id|角色>` 命令可编辑各字段；默认班子补齐完整档案内容（非空）。
- 做到什么程度：档案字段齐全且 CLI 可编辑、可查看。
- 涉及功能：F3；单元 U16。
- 验收标准：测试断言字段齐全、编辑落库、CLI 查看生效。
- 验证方式：pytest + CLI 冒烟。
- 暂不做：档案版本历史、档案导入导出。
- 注意：新增字段走 Alembic 迁移；旧库自动升级路径已有测试模式。

## 子阶段 B：立场与拒绝（U17）

- 做什么：角色对话与写作提示词注入完整档案；构造冲突场景时，角色能依据立场坚持判断或拒绝违背立场的任务（如写手拒绝“按这个违背人设的设定写”、审稿拒绝“放行前后矛盾的稿子”），拒绝有明确理由并留痕。
- 做到什么程度：冲突场景测试通过；拒绝行为可识别（payload 标记 `kind=refusal`）。
- 涉及功能：F3、F4；单元 U17。
- 验收标准：测试构造两个冲突场景断言角色坚持立场 / 拒绝任务；日志可识别。
- 验证方式：pytest。
- 暂不做：拒绝后的自动协商流程（人工/作者介入即可）。

## 子阶段 C：伙伴私有记忆（U18）

- 做什么：新增 `agent_memories` 表（workspace_id / agent_id / content / created_at）；`memory note <workspace_id> <agent_id|角色> --content ...` 写入；`memory notes <workspace_id> [agent_id]` 查看；权限分层：伙伴只能写自己的笔记（命令限定 actor），老板可看全部。
- 做到什么程度：各伙伴笔记互不相同；写手笔记仅写手可写、老板可看。
- 涉及功能：F11；单元 U18。
- 验收标准：测试断言权限分层与内容隔离。
- 验证方式：pytest + CLI。
- 暂不做：记忆自动摘录（从对话自动生成笔记）、记忆衰减。

## 子阶段 D：伙伴状态沉淀（U23）

- 做什么：`Agent` 表新增 `mood` 字段；互动（talk / revise / 被退稿 / 拍板）后按规则更新角色情绪状态并留痕（记录到创作日志 / 消息 payload）；`agents show` 展示当前状态。
- 做到什么程度：互动后状态字段更新且有记录。
- 涉及功能：F12 基础；单元 U23。
- 验收标准：测试断言特定互动后情绪变化可查。
- 验证方式：pytest + CLI。
- 暂不做：复杂情绪模型、情绪影响生成质量的加权。

## 子阶段 E：分层视图与按需检索（U19）

- 做什么：各层默认视图：写手 = 写作记忆包（作品档案 + 风格锚点 + 章纲占位 + 相关私有记忆）；主编 / 责编 = 作品档案 + 最近对话摘要；老板 = 全局概览。按需检索：`memory search <workspace_id> <关键词>` 返回带来源引用的片段（作品档案 / 消息 / 意见 / 版本 / 伙伴笔记）。
- 做到什么程度：默认视图按角色区分；检索结果带来源；上下文内容检查通过。
- 涉及功能：F8、F11；单元 U19。
- 验收标准：测试断言写手默认只拿记忆包、其他角色视图不同；检索带来源；跨作品不串。
- 验证方式：pytest。
- 暂不做：向量检索（先做关键词检索）、检索排序学习。

## 子阶段 F：叙事追踪（U20）

- 做什么：新增 `plot_threads` 表（workspace_id / content / kind（伏笔 / 目标 / 钩子）/ status（planted / pending / recovered / resolved）/ 关联章节占位）；命令：`plot plant <workspace_id> --kind foreshadow --content ...`、`plot list`、`plot recover <thread_id>`；写手记忆包与审稿提示词中注入悬置钩子。
- 做到什么程度：埋设 → 追踪 → 回收流程测试通过。
- 涉及功能：F12；单元 U20。
- 验收标准：测试断言埋设 / 列表 / 回收状态流转；记忆包包含悬置线索。
- 验证方式：pytest + CLI。
- 暂不做：自动检测伏笔回收、跨章关联图。

## 子阶段 G：质量门完善（U21、U22）

- 做什么：
  - U21：新增句式重复率（相同句尾 / 开头短语重复计数）与风格一致性评分（与风格锚点描述关键词的贴合度），并入 `check_quality` 报告；测试集判定达标。
  - U22：`quality explain <draft_id>` 定位 AI 味句段并给出改写建议（命中词 → 提示替换为具体动作 / 感官细节）。
- 做到什么程度：测试集通过率 ≥ 90%；定位与建议可执行。
- 涉及功能：F15、F16；单元 U21、U22。
- 验收标准：测试断言新增维度生效、定位包含原文位置与建议文本。
- 验证方式：pytest。
- 暂不做：基于 LLM 的改写建议（先用规则模板）、风格一致性向量化。
