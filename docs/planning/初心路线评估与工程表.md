## C. 细化设计

### C1. 完结状态机

`publishing --(ending_check 周检 or 周会决策)--> finishing --(publish_batch 递减至 0)--> finished`

- 进入 finishing：`ending_check`（周检，`e556ebb`）或周会报告 decisions；写 `finish_remaining`/`finish_note`。
- 完结停更：`publish_batch` 减到 0 → status='finished'、finish_remaining=0、daily_enabled=false。
- 新书孵化：finished 且无 planning 新书 → 由周会 `next_book` 决策创建 planning（apply_architect）；同一时间只允许一本 planning 新书（防重复）。
- 面板：作品库显示 finishing（剩余 N 章 + 理由）与 finished 状态。

### C2. 留痕类别清单（补齐后全量）

| 类别 | 事件 |
| --- | --- |
| settings | save_settings / apply_schedule |
| operation | run_now / request_run / pause / resume / daily_run（新） |
| agent | save / deploy / auto_fill_action / action_claimed（新）/ action_status（新）/ mail_send（新）/ mail_resolve（新）/ promise_settle（新） |
| guard | guard_check（新，含 issues/constraints） |
| publish | publish / stock_batch / preflight |
| meeting | completed（新）/ round_speech_failed / cancel |
| knowledge | 知识包维护 / 草稿采纳 / 热点刷新 |
| ending | weekly_check / confirm_next_book |

### C3. 人物卡进化数据模型

- `characters.state`：当前状态快照（record_work 已写）。
- `character_evolution`：逐章变化（name/chapter_id/change_log/arc/snapshot）。
- 周会固化：周会报告 `decisions.character_updates`（[{name, change_log, arc}]）→ 幂等写入 characters/character_evolution（source='weekly'）。
- 展示：作品库角色卡时间线（按章节倒序列出 change_log）；`get_meta` 已注入最近 10 条轨迹。
- 清理：`character_evolution` 每书保留最近 200 条，超出按 id 清理（防无限增长）。
