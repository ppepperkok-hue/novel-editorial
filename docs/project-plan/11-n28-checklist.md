## 第 1 层：核心价值（01a）

### 一句话价值主张

为作者解决「伙伴的行为没有后果、沉默没有来历」的问题，带来「被拒会低落、被采纳会起劲、想说没说也留痕、憋久了会自己攒火气」的结果，让编辑部真正开始长出自己的性子。

### 核心用户与核心场景

- 作者本人：连续拒绝写手三次后，他的同类主动建议明显变少；审稿三次指出矛盾被压下后，耐心池见底，作者在 CLI 能看到「审稿快压不住了」；伙伴想说没说，账上查得到他为什么憋着。
- 开源外部作者（次）：默认保守（LLM 提炼关、反馈变化温和），开箱可预期。

### 价值边界（明确不解决）

- 不解决状态攒满后自动召集讨论（那是 N29 的入口，本阶段只做耐心池记账与可见）。
- 不解决动机 / 性格的极端人格化（数值漂移有上下限，不失控）。
- 不做定时器、后台调度、催办（红线不变）。

### 反盲从三问

1. 需求还是方案？「行为有后果、沉默有来历、耐心攒得出」是需求；强度增减、漂移参数、silence 留痕是方案。
2. 依据是什么？回溯 G1（协作自然发生）、G3（伙伴完整度）与 09 已确认的「演化层 / 沉默留痕口径 / 状态阈值三状态」。
3. 不做会怎样？N27 的选择器只有输入没有反馈，性格长不出来，自由意志停在「会选」而没有「会变」。

### 做 / 不做

**做（N28）**：反馈闭环（decide / delegation / talk 点名等真实路径回写动机强度与倾向）、作者「放下」与言语反馈、个性参数漂移（基线 + 漂移 + 缓慢回弹）、沉默留痕（silence 类 + 显著度门槛 + 连续沉默去重）、耐心池三状态计数与 CLI 可见、LLM 动机提炼实装（默认关）。

**不做（N28）**：状态攒满自动发起行动 / 召集讨论（N29）、人工干预面板（后置面板阶段）、极端人格化数值、定时器与后台调度。

### 依赖与实施顺序

反馈闭环（回写动机）→ 作者放下 / 言语反馈 → 沉默留痕 → 个性漂移 → 耐心池 → LLM 提炼 → 可见性与文档 → 全量回归与独立审查。

## 全局约束与风险

- 约束：延续全部红线——不工单化、不强制、作者永远拍板、可解释、可复现；数值漂移有上下限；沉默是可选的，不是惩罚。
- 风险 1：反馈闭环反向干扰业务 → 回写失败只告警不回滚业务（复用 N3 降级模式）。
- 风险 2：沉默 / 耐心账本刷屏 → 显著度门槛 + 连续沉默去重 + 时间线计数上限。
- 风险 3：LLM 提炼引入不稳定 → 默认关、mock 断言、关时零 token。
- 决策记录：状态攒满「自动发起」是 N29 的活，本阶段只把耐心池记账做扎实。
