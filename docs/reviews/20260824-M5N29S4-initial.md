### 问题

#### P3（可后补，不阻塞）

1. patience show 示例输出顺序与实际 CLI 不一致 — docs/usage.md:1039-1043
   「清零进冷却」示例按固定顺序排列，但实际按伙伴创建顺序（created_at, id）输出，id 为随机 uuid，行序每次运行不同。影响：示例自称「mock 下的真实输出」，用户照做会看到不同行序；数值本身正确。修法：改为真实输出顺序，或注明行序可变。
2. 文档称开场消息仍是 discussion_* 事件，实际 events list 不含 discussion_open — docs/usage.md:1007
   open_discussion 以 role=author 记录开场消息，events list 只对 role=agent 的消息写 agent.message 事件，因此 events list 只看得到 discussion_contribution / discussion_summary，看不到 discussion_open。修法：改为「开场是作者消息、不进事件流；发言 / 总结照常出现」，与示例输出一致。
