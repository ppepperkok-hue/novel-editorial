#### Minor（可后补）

1. **P3：带首尾空格的关键词静默漏匹配**
   - 文件：src/novel_editorial/core/views.py（231-234 行）
   - 问题：`keyword.strip()` 只用于空值检查，匹配与片段仍用原始关键词；`inspect <id> " 钩子 "` 返回 no matches。
   - 影响：用户粘贴带空格关键词时查询结果异常为空。
   - 修法：空值检查后 `keyword = keyword.strip()`，匹配与 `_snippet` 统一用剥离后关键词。
2. **P3：命中辅助字段时输出行看不到命中词**
   - 文件：src/novel_editorial/core/views.py（347-351 行）
   - 问题：命中 actor / owner / 标题 / kind / status 等辅助字段时仍渲染内容片段，命中词不可见（如 `inspect foreshadow` 输出行不含 foreshadow，kind 被翻译成“伏笔”）。
   - 影响：用户看不出这条结果为什么命中。
   - 修法：命中辅助字段时在输出行带上该字段（actor/owner/标题前缀、线索 kind/status 命中标记等），保证查询词可见。
