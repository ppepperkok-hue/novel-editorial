#### Minor（可后补）

- 非 ASCII 大小写名字解析失败 — src/novel_editorial/core/agents.py create_agent / resolve_agent
  - 问题：create_agent 与 resolve_agent 用 SQLite `func.lower()` 匹配名字，但 SQLite lower() 只折叠 ASCII；含非 ASCII 大小写字母的名字（如 Émilie、西里尔、希腊字母）即使精确输入也解析不到；create_agent 的重复检查同样失效，大小写变体可被重复创建，破坏作品内名字唯一不变量。
  - 修法：两处统一改用 Python 侧 casefold 比较（作品内伙伴数量少，全量拉取后 Python 比较可接受且确定）。
