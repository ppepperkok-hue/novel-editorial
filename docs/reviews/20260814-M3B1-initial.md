#### Important（应该修）

1. **P2：跨进程同时间戳事件会被 watch 游标永久跳过**
   - 文件：src/novel_editorial/store/events.py（100-105 行）
   - 问题：`_next_event_time` 只靠模块级 `_LAST_EVENT_TIME` 在单进程内保证单调；`events watch` 与产生事件的 CLI 本来就是两个进程。同一微秒（同一时钟 tick）跨进程写入时，后写入但 id 字典序较小的事件会被 `list_events_since` 的 `(time, id)` 游标过滤掉，watch 再也看不到（审查用固定时钟复现）。
   - 影响：watch 永久漏事件，违反 B1 验收标准「watch 能看到新产生的事件」。
   - 修法：改用 SQLite 隐式 rowid（插入序单调递增）作为排序与游标键，时间仅作展示；或插入时基于该 workspace 的 `MAX(time)` 推导时间戳。
