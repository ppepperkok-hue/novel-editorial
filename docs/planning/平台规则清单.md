# 平台规则清单（Phase 0 交付物）

> 整理日期：2026-08-09　|　依据公开资料与开源工具调研整理，正式开工前请以各平台最新官方协议为准。

---

## 番茄小说（全自动首选）

**账号与签约**

- 个人可注册，需实名认证；签约需通过编辑邀请或主动申请，签约后才有完整收益路径。
- 收益路径：全勤奖、听读分成、签约稿费；流量核心是「首秀」机制（验证期后进入公域流量池）。

**AI 内容政策**

- 2025-09-01 起（《人工智能生成合成内容标识办法》施行），作者提交内容时必须如实声明是否使用 AI 生成/合成。
- 平台严禁滥用 AI 工具批量生成低质内容（2025 年 4-5 月治理公告），已有「AI 痕迹检测 + 人工抽检」双机制；未如实申报可能无法过审。
- 违规处罚：下架整改 7 天 / 30 天 / 永久。

**发布机制**

- 作者后台有真实 HTTP 接口（Cookie + X-Secsdk-Csrf-Token 鉴权），开源 MCP 工具 tomato-writer-mcp 支持列书、看数据、发布与定时发布。
- 定时发布为服务端预约，到点自动发出，本机无需常驻；预约成功不保证过审，正式发布仍会审核。
- Cookie 有效期约 1-2 个月，需刷新流程。

**收益门槛（2025 新规）**

- 全勤奖需同时满足：作品签约且累计有效过审字数满 10 万字（次月起）、当月听读分成收益 ≥ 500 元、每日人工更新 4000 或 6000 字且当日审核通过。
- 全勤档位：日更 4000 字约 600 元 + 5% 当月听读分成（上限 1500 元）；日更 6000 字约 800 元 + 5% 当月听读分成（上限 2000 元）。

**自动化建议**

- 存稿池 + 定时发布是保全勤的关键能力；如实标注 AI；质量门前置，避免被判低质水稿。

## 晋江文学城（不建议全自动）

- 2025-02-17《关于 AI 辅助写作使用、判定的试行公告》：仅允许「文字型辅助-校对级、创意型辅助-要素级、创意型辅助-粗纲级」三类 AI 辅助。
- 超出范围视为影响原创性，处罚：锁章、黄牌一个月、永久禁榜（含人工榜与自然榜）；V 文同步退还问题章节全部订阅，且需回退至 AI 介入前的原始稿件方可解锁。
- **结论**：全 AI 正文在晋江不可行；若要在晋江运营，只能人主导、AI 辅助到粗纲，发布必须人工确认。

## 起点 / 阅文

**AI 内容政策**

- 总原则：AI 可辅助，严禁「非真人自动化」批量生成核心内容，人类必须主导创作。
- 官方 AI 工具（作家助手妙笔 / Claw 等）仅用于辅助：大纲、纠错、灵感，禁止生成完整章节。

**发布机制**

- 官方「作家助手」App 原生支持快捷发布与定时发布，可推送到起点中文网、QQ 阅读等阅文系站点。
- 无公开发布 API；网页/客户端自动化存在风险，建议发布动作保留在官方渠道。

**自动化建议**

- 流水线负责「生成草稿 + 质量门 + 排版 + 发布提醒」，由真人过目后通过官方客户端定时发布。

## 海外平台（Royal Road / Webnovel / Wattpad 等）

- AI 政策相对宽松，部分平台要求标注；存在 API 或网页发布通道。
- 中文内容在海外平台的流量逻辑与国内不同，需另行调研目标站规则。

- [ ] 注册小号试错，不用主号冒险

- [ ] 不做内容水化、堆砌、批量低质创作

- [ ] 版权红线：不抄袭、不侵权、不仿写未授权作品
- [ ] 发布日志留档（时间、章节、AI 声明、审核结果、异常）
