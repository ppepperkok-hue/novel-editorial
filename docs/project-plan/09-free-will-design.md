# 09 自由意志设计讨论（Natural Behavior & Free Will Design）

- 建立：2026-08-23（用户与总监讨论归档）
- 定位：立项前设计讨论归档，承接 06 新能力清单 M5「自然行为与自由意志」主线；结论经用户确认后正式并入 06 与实施文档。
- 来源脉络：M1 最小自然行为种子 → N1/N2/N3/N4/N16 落地 → 三项 P3 收口（2026-08-22）→ 2026-08-23 讨论自由意志怎么开发。

## 一句话

自由意志不是随机乱动，而是「行为有内在来源、行为有选择空间、选择随经历演化」；编辑部在协作空间里自然走动，创作大门始终由作者把守。

## 现状：自然行为长到了哪一步

- N1 主动行为引擎：情境 + 条件函数的钩子，业务事件后触发；频次上限（默认每作品每伙伴 3 条）；可全局开关；payload 带 initiator/kind/trigger。
- N2 判断与立场：拒绝 / 重申 / 推翻 / 反驳，跨通道立场历史；作者推翻后确定性拒绝失效。
- N3 行为留痕：behavior_timeline 沉淀印象 / 关系 / 观点，事件溯源式（当前状态 = 每（agent, kind, target）最新条目）；事后追加、失败降级。
- N16 协作网络：伙伴间对话式互委与回应，接受 / 拒绝遵循 N2，拒绝 / 关系沉淀走 N3；不工单化。
- 判断：长出的是「主动性」，不是「自由意志」。触发是确定性条件，同一情境跑一百遍说同一句话；沉淀只被查询展示，不反哺后续行为；伙伴没有「自己惦记着什么」的内在状态。

## 自由意志的工程定义（三层）

1. **动机层**：伙伴心里装着东西——手头惦记的伏笔与目标、对谁的印象、最近被退稿 / 被压下的经历、立场上最紧的那根弦。动机来自档案与事件沉淀，随经历变化。
2. **选择层**：情境与动机碰撞后，产生的不是唯一答案，而是候选集合与各自的倾向；同一件事这回说、下回可能不说，也可能换对象、换说法。倾向 = 情境相关度 × 动机强度 × 个性参数 × 历史反馈（雏形，组合方式待实施细化）。
3. **演化层**：行为结果回到动机层——被拒后倾向降低，坚持成功后倾向升高；性格由此长出来，且全程可追溯。

## 边界与红线

老红线不动：不工单化（无任务队列 / 认领状态机 / 超时惩罚 / 催办）、不设强制关卡、作者永远可介入可拍板、多作品隔离。

新增两条工程红线：

- **可解释**：每次自主行为都能说出动机来源（因为惦记什么、什么情境勾起来的）。
- **可复现**：测试固定随机种子，同一场景可断言；不搞玄学验收。

## 协作链与创作链

链式自走拆成两种，边界不同：

- **协作链**：B 被 A 拒后换方式再动——回头问作者、找 C 商量、自己先消化，C 再回应。只在对话、提醒、互委、讨论里转，**不碰正文**。允许作者不在场时自然走动，事件流全程可见，作者回来随时打断。
- **创作链**：退稿后写手自己重写、审稿自己再审、自己拍板。**守门**：创作动作（写稿、改稿、拍板、放行）需要作者在场或明确授权；写手不会在作者离开时把整章写完还自己拍板。

## 链的起点：状态阈值自发起

- 不做定时器、不做工作日节拍、不做固定晨会（旧 playbook 反面教材）。
- 允许「状态积累到阈值」自然发起：例如审稿连续三次指出矛盾都被压下，攒够了自行召集一次讨论，不靠作者点将。
- 阈值按角色 / 个性可配；需要防抖与冷却，防止伙伴间互相触发风暴（冷却不是调度器，是防失控）。

## 沉默：定义、留痕与演化

- 用户确认：沉默需要留痕。
- 工程定义：不是每条消息不回都叫沉默；「评估过、和自己相关、但选择不开口」才算。无关消息不回是自然，不配进时间线。
- 留痕形式：behavior_timeline 新增一类记录（kind 待定，如 silence / omission），记谁、什么情境、对谁、评估出的倾向、最终没说出口。
- 演化：连续沉默使后续参与倾向降低；被作者点名或遇到真正要紧的事后回升。沉默是可选的，不是惩罚机制。

## 分阶段路线（候选，待正式立项）

1. **第一阶段：动机层 + 行为选择器**。让「同一情境下伙伴可能做出不同选择」，自由意志的地基；含动机来源、候选 + 权重、确定性 seed 下可复现。
2. **第二阶段：反馈闭环 + 沉默权**。N3 沉淀反哺倾向；允许「觉得不值当就不开口」，沉默留痕并影响演化。
3. **第三阶段：N4 编辑部自然讨论形态**。分歧攒到一定程度自动开起来，作者旁听、随时介入；与现有「点将 / 通气 / 总结 / 落盘」方向合并。

## 已收敛的设计决策（2026-08-23 讨论确认）

- **动机显式表**：字段为 agent / 动机类型（枚举）/ 内容文本 / 强度 / 来源事件 / 创建时间 / 最后触碰时间；生命周期为产生、增强、衰减（复用 N17 机制）、清空。
- **动机产生**：第一阶段以确定性规则映射（事件 → 动机模板）打底；LLM 提炼做成可开关功能（默认关，需要时开启），与 proactive_enabled 同级。
- **动机强度演化**：只由事件沉淀与行为反馈自然增减；作者通过「言语反馈」（点名 / 表扬 / 批评 / 说放下）与「放下」指令间接影响，相当于 N2 作者推翻的语义。
- **人工干预后门**：保留直接调整动机强度的通道（如面板旋钮），但每次干预盖戳、来源标记为 author_adjust，全程可溯；真实自然演化仍是默认路径。
- **动机可见**：作者可在 CLI / 面板看到每个伙伴的动机、强度与来源（可解释红线）。
- **个性参数**：显式新增档案字段（具体最小集待定），不靠模型从文本猜性格；进选择器权重。
- **状态阈值**：不写死，按角色 / 个性参数计算（如耐心值低者被压下两次就召集讨论，高者可压五次）。
- **动机 ≠ 待办**：无时限、无催办、可搁置可淡忘，只影响行为倾向；不与任务队列语义混淆。
- **个性参数最小集（2026-08-23 确认）**：主动性（多爱自己找事）、坚持度（被拒之后还坚不坚持）、表达欲（话多话少，沉默倾向底座）、耐心（被压下几次才发作，状态阈值底座）；均进选择器权重。
- **自由程度旋钮（2026-08-23 确认）**：作品级 / 伙伴级可配「随机度」0–1；0 永远选最高权重候选（保守可预期），1 偶尔选低权重但更野的候选；作为「自然行为限度放宽」的工程正主，现版本默认保守，后续放宽即抬默认值，不改机制。
- **选择器机制轮廓（2026-08-23 确认）**：候选两层生成——预定义模板 + 个性参数挑语气变体打底，LLM 候选随提炼开关（默认关）；权重 = 情境相关度 × 动机强度 × 个性参数 × 历史反馈；加权随机选中一个，固定 seed 可复现、换 seed 有变体；沉默评估同线（确定性粗筛 → 权重低于阈线 → 落沉默留痕），避免每条消息惊动所有伙伴。
- **创作链守门粒度（2026-08-23 确认）**：只读报告类（质量门 / 一致性核查 / 设定影响分析 / 讨论 / 提醒 / 互委）全部放开，作者不在场也可自动转；准备类（打腹稿、列提纲、拟修改方案，不落正文）放开，停手点在落笔；正文的写 / 改 / 拍板必须作者在场或明确授权；授权分「一次动作授权」与「区间授权」（如改到过质量门再停），区间授权必须有明确终点。
- **时间机制（2026-08-23 确认）**：延续 N17 懒惰时间哲学——记录全带 UTC 时间戳、append-only 可回放；时间流逝靠懒算（记忆衰减查询时现算 / 手动 decay 落库），无定时器、无后台调度。自由意志的动机衰减、耐心冷却、无视判定都在「下次触碰时」结算，时间是被回忆出来的，不是闹钟扫出来的。
- **评估管线三层（2026-08-23 确认）**：事件后先确定性粗筛（角色职责 + 议题关键词 + 动机命中，不相关直接跳过，零成本）→ 对相关方本地算「说话欲」权重（纯数学，不调 LLM）→ 只有真开口的才请 LLM 造句（随提炼开关，默认关，日常零 token 开销）。
- **沉默留痕口径（2026-08-23 确认）**：不是每次没说话都记；只在「动机过了显著线、且对这个议题的倾向值实际变化」时才落库，同一伙伴对同一议题连续沉默且倾向不动时不重复记；不相关场合的没吭声不算沉默、不记。
- **验收标准五条（2026-08-23 确认）**：每一条都可写成机器可断言的测试——(1) 变体：同场景换 seed 行为不同（有选择，不是写死）；(2) 演化：被拒 N 次后同类主动倾向下降、坚持成功者更坚持（行为被经历改变）；(3) 沉默可查：该说没说、想开口但憋住，账上查得到；(4) 开关生效：关主动性全员静默、关提炼零 token；(5) 不失控：作者拍板不可绕过、创作链无授权不写正文。

### 收口补充（2026-08-23）

- **状态阈值三状态**：被拒、被压下、分歧未决为第一批计入；按伙伴视角各自记账；「无视」判定事件驱动（下次触碰时回看，不设倒计时）；耐心池见底触发行动，清零进冷却，未解决重新攒。

- **权重公式**：标为实施期细节，不在本设计里细磨；立项清单只给硬约束——四样乘出倾向、归一化、固定 seed 可复现、历史反馈用被拒 / 被采纳计数折算。
