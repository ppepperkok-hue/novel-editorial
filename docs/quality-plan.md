# 小说质量提升路线图

## 已落地（2026-08-10）

1. **模型分级**：策划与写手用 `deepseek-v4-pro`（质量优先），润色 / 审稿 / 记忆提取用 `deepseek-v4-flash`（成本可控）
2. **聚焦上下文**：写手与审稿不再吞整包记忆 JSON，改为逐项注入——风格指南、上一章结尾（800 字）、最近摘要、角色状态、活跃伏笔、已有标题、卷目标
3. **蓝图优先**：策划环节先查预排的 10 章蓝图，若当前章节已有蓝图则必须沿用其标题 / 大纲 / 钩子，不再每日另起炉灶
4. **机械质量门**：硬性拦截 AI 高频词——`突然` >1、禁止词（不由自主 / 情不自禁 / 微微一愣 / 缓缓说道 / 与此同时 / 一股强大的气息）>3、连续 `！！/？？`、感叹号 >8、省略号 >5、字数 <1500
5. **重写路径修复循环**：审稿不达标（score<7 或未通过）时，把审稿意见回喂写手重写，最多 3 轮

## 下一步（按优先级）

1. **n8n 每日链路修复循环**：审稿不过 → 自动回写手改稿（最多 2 轮），而不是直接失败
2. **真实阅读数据回填**：上架后接入番茄完读率 / 追读率，低质章节反查大纲与钩子问题
3. **章节评分沉淀**：每章分数写入记忆包，后续写作自动避开弱项（节奏 / 对话 / 钩子）
4. **伏笔账本自动化**：蓝图标记投放章与回收章，写后校验账本闭环
5. **多候选择优**：写手一次出 2 稿，审稿打分选优，成本翻倍但质量上限更高
6. **长程检索**：按角色 / 设定 / 标题关键词检索历史章节摘要，补足 10 章以外的长线记忆
7. **风格一致性校验**：生成后用风格指南对章节做相似度与语域检查

## 质量指标（建议跟踪）

- 审稿通过率、平均分数（words / plot / style / punctuation / coherence）
- 机械质量门命中率（AI 词、标点超限）
- 上架后的完读率与追读率、低质章节占比
