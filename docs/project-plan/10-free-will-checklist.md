# N27 自由意志引擎立项清单（Phase 0 · 完整流程）

- 建立：2026-08-23
- 定位：M5「自然行为与自由意志」主线深化；设计讨论与结论见 [09-free-will-design.md](09-free-will-design.md)。三阶段路线：**N27 动机与行为选择器（当前立项）** → N28 反馈闭环与沉默 → N29 编辑部自然讨论（N4 深化）。本清单只详拆 N27，N28 / N29 只保留方向（05a 纪律）。
- 前置：N1 主动行为引擎、N2 判断与立场、N3 行为留痕、N16 协作网络、N17 记忆衰减均已收口。

## 第 1 层：核心价值（01a）

### 一句话价值主张

为作者解决「编辑部伙伴像提线木偶，只在我敲命令之后按固定条件反应」的问题，带来「伙伴心里有惦记、同一件事会做不同选择、经历会慢慢改变他们」的结果，让协作更像和真人共事。

### 核心用户与核心场景

- 作者本人：写手交稿后，审稿这次主动提矛盾、下次选择沉默；被退稿三次的写手不再提同类建议；作者随时能看到每个伙伴在惦记什么、性子多野。
- 开源外部作者（次）：默认保守旋钮，开箱体验稳定可预期；想要更活的编辑部就把自由程度调高。

### 价值边界（明确不解决）

- 不解决作者不在场时的无人监督全文自动写作（创作链守门，红线）。
- 不解决真实人格模拟、通用聊天、跨作品记忆共享。
- 不做定时器、后台调度、任务队列、催办（红线不变）。

### 反盲从三问

1. 需求还是方案？「伙伴行为有内在来源、有选择空间、随经历变化」是需求；动机表、倾向权重、随机度旋钮是方案。
2. 依据是什么？回溯 G1（协作自然发生）、G3（伙伴完整度）与 06 清单 M5 主线；自由意志是 M1 埋下的自然行为种子的深化，不是新方向。
3. 不做会怎样？编辑部停在反应式，性格演不出来，「越协作越有来历」缺了内在那一半。

### 做 / 不做

**做（N27）**：动机表与服务（确定性规则产生 / 增强 / 衰减 / 清空，衰减复用 N17 机制）、动机 CLI 可见、个性参数四字段（主动性 / 坚持度 / 表达欲 / 耐心）、行为选择器（三层管线：粗筛 → 权重 → 加权随机固定 seed，模板候选打底）、历史反馈计数进权重、自由程度旋钮与开关、提炼开关占位（默认关，引擎后置 N28）。

**不做（N27）**：LLM 提炼引擎实现（后置 N28）、沉默留痕落库（后置 N28，评估入口与倾向计算保留）、状态阈值自发起（后置 N28 / N29）、N4 讨论形态（N29）、动机强度的人工干预面板（后置面板阶段，N27 先留 CLI 通道）。

### 依赖与实施顺序

动机表 → 动机服务与 CLI → 个性参数 → 选择器（含历史反馈）→ 触发点接入 → 旋钮开关 → 可见性与文档 → 全量回归与独立审查。

## 全局约束与风险

- 约束：延续「不工单化、不设强制关卡、作者永远可拍板、可解释、可复现」全部红线；数据按作品隔离；动机只影响行为倾向，无时限、无催办。
- 风险 1：加权随机带来行为不稳定 → 固定 seed 复现 + 换 seed 变体断言；随机度可归零回到确定性。
- 风险 2：动机表膨胀刷屏 → 容量上限 + 衰减 + 清空闭环；只记「相关且倾向变化」的沉默。
- 风险 3：日常路径性能退化 → 三层管线，粗筛与权重纯本地计算，LLM 只在真开口时按开关调用。
- 风险 4：创作链失控 → 守门粒度已定（只读与准备放开、正文写改拍板要作者在场或授权），测试断言无授权不写正文。
- 决策记录：自由程度旋钮是「自然行为限度放宽」的工程正主；现版本默认保守，后续放宽只抬默认值、不改机制。
