## 红线（继承 06 清单，本阶段强制）

1. 判断是**可记录的表达，不是审批关卡**：拒绝、反驳、坚持立场不阻塞协作；作者可随时再下指令、可明确推翻，推翻同样留痕；不得出现"必须说服伙伴才能继续"的强制节点。
2. 不引入任务队列、认领状态机、超时惩罚等调度器语义（不工单化）。
3. 兼容 N1：主动行为、talk 首轮提问、rebuttal 既有行为不破坏；拒绝/反驳与主动消息的 payload 语义可区分。

## 子阶段 B1：判断模型与立场坚持

### 做什么

- 保留并深化 `check_refusal`：拒绝判定仍以确定性立场规则为底座（可断言），拒绝文案与立场/价值观字段关联，payload 稳定为 `{"kind": "refusal", "stance": "<立场摘要>"}`（或等价可追溯结构，具体字段以最小改动为准）。
- **立场坚持**：同一冲突被再次提出时，伙伴能识别"这个问题我拒绝过"，回应为重申立场而非全新回复；判定用确定性规则（如冲突关键词 + 已有同类 refusal 历史），mock 下可断言。
- 拒绝与重申消息落 messages（role=agent、payload 带 kind=refusal），并同步 agent.message 事件；作者消息照常落库。
- 作者最终决定权不变：拒绝后作者可继续其他指令；明确推翻（如"以老板身份定了，就这么写"）正常推进并留痕。

### 做到什么程度

- 至少一个端到端用例：同一冲突第二次提出时，伙伴重申立场（输出与落库可识别为坚持，而非无条件服从）；
- 拒绝消息与重申消息 payload 可追溯（kind 与立场上下文稳定可断言）；
- 现有写手/审稿/责编三条拒绝规则保持或按等价规则迁移，既有测试不破坏；
- 关闭/不关闭 proactive 不影响判断逻辑（拒绝是判断，不是主动行为）。

### 验收标准

- 单元测试：拒绝判定、重申判定、payload 结构、作者继续指令不受阻塞、推翻留痕；
- 端到端用例：拒绝 → 重申 → 作者继续/推翻 全链输出与落库可断言；
- 现有 314+ 测试全绿。

### 验证方式

pytest + ruff + pyright + 宪法校验 + CLI 冒烟（mock 下可断言）。

### 暂不做

- LLM 自由判断取代规则表（先确定性规则，语气多样性后续）；
- 拒绝/分歧对关系的演化（N3）；
- 伙伴互委（N16）。

### 变更记录（实施中已回写）

- 推翻口径：作者 override 后，该 rule 在本工作区的确定性拒绝失效，后续命中同 rule 关键词的消息走原有 LLM 正常路径；立场仍在 prompt 中自然表达，override 记录继续留痕。
- 留痕匹配：`has_same_rule_refusal` / `has_same_rule_override` 用 SQLite `json_valid` + `json_extract`（CASE 守卫）+ 等值比较，与 JSON 序列化格式无关；LIKE 通配符与谓词求值顺序两类风险均已消除。
- 审查链五轮收敛，P1 误报核实与 P3 测试有效性说明见 docs/reviews/20260817-M5N2B1-fix3.md 与 -fix4.md。

## 子阶段 B2：反驳与分歧记录

### 做什么

- 把写手反驳从"revise 自动生成"扩展为**可识别的判断表达**：反驳消息稳定携带 `kind=rebuttal`（现有）+ 可引用针对的 agent 意见；保持既有行为不变。
- 分歧可见性：拒绝/反驳在 events 流可追溯（agent.message payload 已带 kind；talk list 已有主动标记，拒绝/反驳保持现状或按需要补最小标记）；提供查看分歧历史的既有入口（events list --type agent.message）并补测试锁定。
- 不新增表结构；分歧通过既有 messages/events 的 payload 标记承载。

### 做到什么程度

- 分歧（refusal / rebuttal）消息与事件带稳定 payload，CLI 可辨认来源与类型；
- 端到端用例：意见 → 写手反驳 → 修订，全链反驳留痕可追溯；
- 与 N1 主动消息区分清晰（refusal/rebuttal 不计入主动频次，N1 已实现）。

### 验收标准

- 单元测试：反驳 payload、events 落库、talk list / events list 可辨；
- 全量 314+ 测试全绿，smoke_m3 仍 OK。

### 验证方式

pytest + ruff + pyright + 宪法校验 + smoke_m3 + CLI 冒烟。

### 暂不做

- 分歧的专门统计面板（N10 跨作品视图时再议）；
- 分歧演化时间线（N3）；
- 编辑部讨论形态（N4）。

### 变更记录（实施中已回写）

- rebuttal payload 稳定为 `{"initiator": "agent", "kind": "rebuttal", "targets": [...]}`，targets 按 agent 意见出现顺序去重、排除写手自评；无其他伙伴意见时不产生反驳消息。
- talk list 对 refusal / rebuttal / override 分别输出 `[agent·分歧·拒绝]` / `[agent·分歧·反驳]` / `[agent·分歧·推翻]`，主动标记不回退；docs/usage.md 已同步说明。
